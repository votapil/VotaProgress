# VotaProgress - заметки для разработки

Мод для Claude Code: план задачи в панели сбоку и в строке под вводом, обзор планов всех проектов.

## Команды

```
claude --plugin-dir .          # запустить Claude Code с модом из этой папки
claude plugin test .           # тесты
claude plugin validate .       # проверка мода
npx -y -p typescript tsc -p .claude-plugin/types/tsconfig.json
```

Перед правкой мода загрузи навык `plugin-authoring`: в нём типы и справочник движка.

## Устройство

- `hooks/plan.ts` - модель плана и всё, что из неё считается. Чистые функции.
- `hooks/storage.ts` - записи по сессиям в хранилище мода: ключи `s:<sessionId>`, отметки `drop:<sessionId>:<planId>`, чистка старше 365 дней. Планы проверяются поштучно, битый пропускается.
- `hooks/tool.ts` - инструмент `progress` для модели.
- `hooks/rule.ts` - правило в системном промпте и напоминания.
- `hooks/query.ts` - что показывает обзор: папки, порядок, поиск, фильтры, команда запуска. Чистые функции.
- `hooks/pane.tsx` - панель, вид «этот чат».
- `hooks/overview.tsx` - панель, вид «все проекты».
- `hooks/register.tsx` - все хуки. Срез хранилища для обзора лежит в переменной модуля, в `$.state` только номер ревизии.
- `types/index.d.ts` - контракт состояния. Без импортов.
- `docs/` (локально, в git не входит) - спецификация и планы этапов.

## Договорённости

- Процентов нет нигде: ни в панели, ни в обзоре, ни в ответах модели. Только счёт «3 из 7».
- Пометок «сейчас» и «ждёт ответа» у шага нет: активный виден по кружку `◐`. Крупный шаг (`big: true`, хранится как вес 3) - значок `◆`.
- Фон панели не трогаем: зазоры у края окна - поля терминала.
- Тексты мода на русском, дефис вместо тире.
- Сначала падающий тест, потом код.

## Разработка в ветке

Мод грузится во всех сессиях из основной папки через `CLAUDE_CODE_PLUGIN_DIRS` в `~/.claude/settings.json`, поэтому ветку держим в соседней папке (`git worktree`). Переменная из `settings.json` перекрывает переменную оболочки, а `--plugin-dir` грузит мод второй копией рядом с основной. Консоль только с модом из ветки:

```
claude --settings '{"env":{"CLAUDE_CODE_PLUGIN_DIRS":"<папка ветки>"}}'
```

Хранилище у обеих копий общее: его имя считается от `votaprogress@inline`, а не от пути.

## Отложено

- подрезка хранилища по размеру: `$.store` держит 4 МиБ на всё, план занимает 1-1,5 КБ, при активной работе место кончится раньше годовой подрезки; нужен отдельный план;
- сбой хранилища виден только в панели, не в строке под вводом;
- два шага с одним `after` встают в обратном порядке;
- `done` на выброшенном шаге возвращает его в план;
- слэш-команда сразу после сжатия съедает напоминание о плане;
- два одновременных вызова инструмента теряют одно изменение.
