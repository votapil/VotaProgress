# VotaProgress

Мод для Claude Code: показывает, что уже сделано по задаче и что осталось.

**Статус: в разработке.** Сейчас в репозитории только каркас.

## Что будет уметь

- **Панель сбоку от чата.** Проект, цель, шаги, процент и критерий конца. Переключился на консоль и сразу видно, чем она занята.
- **Строка под вводом.** То же одной строкой, когда панель закрыта.
- **План ведёт модель.** Мод даёт ей инструмент `progress`: завести план, отметить шаг, закрыть. Шаги имеют вес 1-3, процент считает мод.
- **Обзор проектов.** Планы из всех чатов по папкам, поиск, фильтры и команда `claude --resume` для возврата в незаконченный чат.

## Установка

Появится вместе с первой рабочей версией.
