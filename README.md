# VotaProgress

Мод для Claude Code: показывает, что уже сделано по задаче и что осталось.

Переключился на консоль и сразу видно, чем она занята и на каком шаге.

## Что умеет

- **Панель сбоку от чата.** Проект, цель, шаги, счёт «сделано 3 из 7» и критерий конца. Процентов нет: план растёт по ходу работы. Панель перерисовывается сама, когда модель отмечает шаг.
- **Строка под вводом.** То же одной строкой, когда панель закрыта или не поместилась.
- **План ведёт модель.** Мод даёт ей инструмент `progress`: завести план, отметить шаг, добавить или убрать шаги, закрыть. Крупный шаг помечен значком `◆`.
- **Сам закрывает план,** когда все шаги сделаны и ход закончился.
- **Напоминает модели** завести план, если она правит уже третий файл без плана, и возвращает ей план после сжатия контекста.
- **Хранит планы 12 месяцев** по сессиям, на вашем компьютере. Наружу ничего не отправляет.

Команда `/progress` открывает панель, если вы её закрыли.

## Установка

Нужен Claude Code 2.1.275 или новее.

```
/plugin install votaprogress --marketplace votapil/VotaProgress
```

Claude Code спросит, добавить ли источник (`y`), и куда поставить мод: для себя во всех проектах или только в текущий.
