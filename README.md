# VotaProgress

Мод для Claude Code: показывает, что уже сделано по задаче и что осталось.

Переключился на консоль и сразу видно, чем она занята и на каком шаге. Открыл обзор и видно, в каком чате какая задача брошена на полпути.

## Что умеет

- **Панель сбоку от чата.** Проект, цель, шаги, счёт «3 из 7» и критерий конца. Процентов нет: план растёт по ходу работы. Панель перерисовывается сама, когда модель отмечает шаг. Ниже - закрытые планы этого чата и строка `----- сжатие -----` там, где сжимался контекст.
- **Строка под вводом.** То же одной строкой, когда панель закрыта или не поместилась.
- **План ведёт модель.** Мод даёт ей инструмент `progress`: завести план, отметить шаг, добавить или убрать шаги, закрыть. Крупный шаг помечен значком `◆`.
- **Сам закрывает план,** когда все шаги сделаны и ход закончился.
- **Напоминает модели** завести план, если она правит уже третий файл без плана, и возвращает ей план после сжатия контекста.
- **Обзор всех проектов.** Планы из всех чатов по папкам, текущая папка первой. Раскрытый план показывает шаги и команду `cd '<папка>' && claude --resume <id>`, которая возвращает в тот чат. Поиск по цели и шагам, фильтры по статусу и периоду, история законченных планов.
- **Хранит планы 12 месяцев** по сессиям, на вашем компьютере. Наружу ничего не отправляет.

## Как пользоваться

- `/progress` - открыть панель, если вы её закрыли.
- `/progress all` - открыть сразу обзор всех проектов.

Клавиши, когда панель в фокусе:

| Клавиша | Что делает |
|---|---|
| `p` | обзор всех проектов |
| `b` | назад к этому чату |
| `r` | перечитать планы других чатов |
| Enter | раскрыть папку или план |
| `c` | скопировать команду запуска раскрытого плана |
| `x` | выбросить незаконченный план другого чата |
| Tab | по кнопкам, полю поиска и фильтрам |

Если копирование не сработало, мод так и скажет: команда видна в панели текстом, её можно выделить.

## Установка

Нужен Claude Code 2.1.275 или новее.

```
/plugin install votaprogress --marketplace votapil/VotaProgress
```

Claude Code спросит, добавить ли источник (`y`), и куда поставить мод: для себя во всех проектах или только в текущий.

## Разработка

```
claude --plugin-dir <папка с модом>
claude plugin test .
claude plugin validate .
```
